# Running the lab without Ansible or Molecule

The network harness and probes are ordinary Python scripts. Molecule supplies
lifecycle sequencing; Ansible applies the example firewall rules. Neither is
required to create the two segments or make guest-to-guest assertions.

For a smaller project, retain `topology.yml`, `scripts/lab.py`,
`scripts/probe.py`, and `molecule/default/tests/test_traffic.py`. Put your
guest setup in cloud-init user-data generated by `scripts/lab.py` or in a shell
script run over the generated SSH ports. Then use:

```sh
python3 scripts/lab.py up
# Configure the guests and install /usr/local/bin/lab-probe.py on probe VMs.
python3 -m pytest molecule/default/tests/test_traffic.py -q
python3 scripts/lab.py down
```

If you replace the echo service with your own application, make each negative
probe target a port with a verified listener. Bind each probe to a test-network
source address and verify its route. A UDP scan that merely times out cannot
distinguish a firewall drop from an absent service.

For faster container-based labs, [containerlab](https://containerlab.dev/manual/kinds/linux/)
can wire Linux containers into a topology. Containers share the host kernel;
QEMU guests are a closer match for tests of a VPS operating system and its
firewall service.
